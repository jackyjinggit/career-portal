壳开源了，然后呢？
方向谁决、偏航谁拦、谄媚谁防

2026 年，Agent Harness 的开源让「谁来动手」被标准化。但壳解决不了三件事——方向谁决、偏航谁拦、谄媚（模型一味顺着人说）谁防。这三件事不在壳的能力范围里，在壳和人的关系里。

壳标准化之后，腾出来的不是真空，是让治理层好好长出来的空间。
能力够了，扶手呢？
玄览是什么
🧭

治理 / 规划 agent

方向、边界、节奏的协调者。架在任意 harness 之上，不做另一套壳，做壳之上的那一半——治理层。

🔍

架构合规检测器

偏离自检：死指针、旧路径残留、版本漂移三类漂移的只读巡检，严格不改文件，磁盘即权威源。

🔌

即插即用 drop-in

已在 opencode、WorkBuddy 验证可跑；Claude Code 可直接 drop-in 接入。不改原 agent 执行逻辑，只在外层叠加治理。
